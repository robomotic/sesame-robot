# Plan: Add Servo Subtrim UI to Captive Portal

## Summary
Add a new "Trims" section to the web UI that allows users to adjust servo subtrim values (+/-) for each of the 8 servos (L1, L2, L3, L4, R1, R2, R3, R4) and save them persistently.

## Current State
- Subtrim values are stored in `int8_t servoSubtrim[8]` (line 76 of `.ino`)
- Subtrim is applied in `setServoAngle()` (line 571-577): `constrain(angle + servoSubtrim[channel], 0, 180)`
- Serial CLI has subtrim commands but no web access
- The `/getSettings` endpoint returns settings as JSON but does not include subtrim
- Motor labels in the UI: S0=R1, S1=R2, S2=L1, S3=L2, S4=R4, S5=R3, S6=L3, S7=L4

## Implementation Steps

### 1. Add Backend Endpoints in `sesame-firmware-main.ino`

#### 1a. Add `/getSubtrim` endpoint
- Create `handleGetSubtrim()` function
- Return JSON array of 8 subtrim values: `{"subtrim":[0,0,0,0,0,0,0,0]}`
- Register in `setup()`: `server.on("/getSubtrim", handleGetSubtrim);`

#### 1b. Add `/setSubtrim` endpoint  
- Create `handleSetSubtrim()` function
- Accept query params: `motor` (1-8) and `value` (-90 to 90)
- Update `servoSubtrim[motor-1]` with the value
- Apply immediately to the servo if currently attached by calling `setServoAngle()` with the current position
- Return 200 OK on success, 400 on invalid input
- Register in `setup()`: `server.on("/setSubtrim", handleSetSubtrim);`

#### 1c. Add `/resetSubtrim` endpoint
- Create `handleResetSubtrim()` function
- Reset all `servoSubtrim` values to 0
- Return 200 OK
- Register in `setup()`: `server.on("/resetSubtrim", handleResetSubtrim);`

#### 2c. Add JavaScript Functions
```javascript
// Load subtrim values when page loads
function loadSubtrim() {
  fetch('/getSubtrim').then(r => r.json()).then(data => {
    for (let i = 1; i <= 8; i++) {
      const el = document.getElementById('trim' + i);
      if (el) {
        el.textContent = data.subtrim[i-1];
        updateTrimColor(el, data.subtrim[i-1]);
      }
    }
  }).catch(console.log);
}

function updateTrimColor(el, value) {
  if (value > 0) el.style.color = '#2ecc71';
  else if (value < 0) el.style.color = '#e74c3c';
  else el.style.color = 'var(--content-color)';
}

function adjustTrim(motorNum, delta) {
  const el = document.getElementById('trim' + motorNum);
  if (!el) return;
  let currentValue = parseInt(el.textContent);
  let newValue = currentValue + delta;
  // Clamp to -90 to 90
  newValue = Math.max(-90, Math.min(90, newValue));
  el.textContent = newValue;
  updateTrimColor(el, newValue);
  // Send to firmware immediately
  fetch(`/setSubtrim?motor=${motorNum}&value=${newValue}`).catch(console.log);
}

function saveTrims() {
  // Save is immediate - just confirm to user
  alert('Trims saved! Values are applied immediately.');
}

function resetTrims() {
  if (!confirm('Reset all trim values to 0?')) return;
  fetch('/resetSubtrim').then(() => {
    for (let i = 1; i <= 8; i++) {
      const el = document.getElementById('trim' + i);
      if (el) {
        el.textContent = '0';
        updateTrimColor(el, 0);
      }
    }
  }).catch(console.log);
}

// Add loadSubtrim to DOMContentLoaded
document.addEventListener('DOMContentLoaded', () => {
  loadTheme();
  loadSubtrim();
});
```

## Key Design Decisions
1. **Immediate apply**: Each +/- button press sends the value to firmware immediately, so the user can see the servo move in real-time
2. **"Save Trims" is informational**: Values are already applied immediately, the button provides user feedback
3. **Reset option**: Quick reset button to zero all trims
4. **Color feedback**: Positive values show green, negative show red, zero shows theme color
5. **Range**: -90 to +90 degrees, matching the serial CLI constraints
6. **Motor numbering**: Uses 1-8 to match the existing manual motor control UI
